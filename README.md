# Customer-Behavior-Analysis
Data Analytics Project Showcasing Customer Behavior Analysis using Python ,SQL, Power BI.

## Overview
This project demonstrates an end-to-end data analytics workflow, starting from data collection and preparation to analysis and business reporting.

The project includes loading and exploring a dataset using Python, performing Exploratory Data Analysis (EDA), cleaning and transforming data, analyzing data using SQL queries in MySQL, creating an interactive Power BI dashboard, generating a business report, and preparing a presentation using Gamma.

The goal of this project is to extract meaningful insights from data and present them through clear visualizations and recommendations.

## Project Steps

### 1. Data Loading
- Imported the dataset into Python using Pandas.
- Reviewed dataset structure, columns, and data types.

### 2. Exploratory Data Analysis (EDA)
- Analyzed data distributions and patterns.
- Identified missing values, duplicates, and inconsistencies.
- Created visualizations to understand trends and relationships.

### 3. Data Cleaning & Transformation
Performed data preprocessing including:
- Handling missing values
- Removing duplicate records
- Correcting data formats
- Creating new calculated columns
- Preparing clean data for analysis

### 4. SQL Analysis Using MySQL
- Loaded cleaned data into MySQL.
- Created SQL queries to answer business questions.
- Used:
  - SELECT statements
  - Filtering
  - Aggregations
  - GROUP BY
  - JOINS
  - Window Functions

### 5. Power BI Dashboard Development
Created an interactive dashboard to visualize key insights.

Dashboard features:
- KPI cards
- Trend analysis
- Category breakdown
- Customer analysis
- Interactive filters and slicers

### 6. Report & Presentation
- Created a business report summarizing findings.
- Developed a presentation using Gamma highlighting:
  - Project objective
  - Analysis process
  - Key insights
  - Business recommendations
